A one-line warning label for a time machine, 120 characters at most, aiming for the biggest laugh: it turns the grandfather paradox into the joke, deadpan, with the surprise saved for the last few words.

> WARNING: Do not kill your grandfather. He is the only one who knows the Wi-Fi password.

## Run it

```sh
node main.ts
```

This writes the label to `/output/entry.txt`.
